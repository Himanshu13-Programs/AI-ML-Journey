# AI / ML Journey
### Himanshu Bohara

This repository documents my hands-on journey through AI and Machine Learning engineering — from mathematical foundations to production-ready systems. Every folder here is a real project built on real data, with documented decisions, honest results, and working code.

This is not a collection of tutorials followed. It is a record of problems solved, models built, and lessons learned — including the failures.
